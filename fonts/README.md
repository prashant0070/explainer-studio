# Fonts

All fonts here are licensed under the SIL Open Font License 1.1 — free for
commercial video. License texts are alongside the files.

| Font | Author | Used for |
|---|---|---|
| Anton | Vernon Adams | display numbers, titles, captions |
| Barlow Condensed (SemiBold/Bold/ExtraBold) | Jeremy Tribby | labels, kickers, credits |
| JetBrains Mono (variable) | JetBrains | counters, tick labels |

Downloaded from [google/fonts](https://github.com/google/fonts) (ofl/).
To swap fonts, drop OFL/free-licensed TTFs in this directory using the same file
names, or point `style.font_dir` in your project spec at another directory.
